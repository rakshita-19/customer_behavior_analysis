# Data Analytics Project

## Overview

This project demonstrates a complete end-to-end data analytics workflow, from data collection and cleaning to visualization and reporting. The objective was to analyze customer shopping behavior data, extract meaningful insights using SQL and Python, and present the findings through an interactive Power BI dashboard and business presentation.

---

## Dataset

**Dataset:** Customer Shopping Behavior Dataset

The dataset contains information related to customer purchases, demographics, product categories, spending patterns, and shopping preferences. It was used to identify trends, customer behavior, and key business insights.

### Key Features

* Customer ID
* Age
* Gender
* Product Category
* Purchase Amount
* Payment Method
* Location
* Shopping Frequency
* Customer Ratings

## How to Run

### Python Analysis

1. Clone the repository.
2. Install required packages:

```bash
pip install pandas numpy matplotlib seaborn
```

3. Open Jupyter Notebook.

4. Run the notebooks in the following order:

   * Data Loading
   * Data Cleaning
   * EDA

### SQL Analysis

1. Import the cleaned dataset into:

   * PostgreSQL
   * MySQL
   * SQL Server

2. Execute the SQL scripts available in the SQL folder.

### Power BI Dashboard

1. Open the `.pbix` file in Power BI Desktop.
2. Refresh the data connection.
3. Explore the dashboard visuals and filters.
